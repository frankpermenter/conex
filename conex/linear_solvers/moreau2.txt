Goal: Replace the DiffWoodbury stub (cuDSS fallback) with a direct Schur complement backward pass exploiting the Woodbury problem structure (diagonal P + low-rank A).

Architecture: Solve (J'J + εI)w = rhs_bar via block elimination (eliminate y_s diagonal, eliminate y_τ scalar, Woodbury solve on reduced (n+m) system), then compute y_out = J*w. Mirrors forward solve_core pattern with different diagonal weights. Extended F_all by 1 row for c1 vector.

Tech Stack: C++/CUDA, cuBLAS (batched GEMV/GEMM), cuSOLVER (batched Cholesky), custom CUDA kernels.

/**
 * Compute s-elimination diagonals from H values.
 * For each dual variable i (0..m):
 *   h_i = 1.0 for zero cones (i < k), h_nonneg[i-k] for nonneg cones
 *   g[i]      = 1.0 / (1.0 + h_i*h_i + eps)
 *   Lambda[i] = 1.0 - g[i] = (h_i*h_i + eps) / (1.0 + h_i*h_i + eps)
 *   gh1[i]    = g[i] * (1.0 + h_i)   // for z-block RHS correction
 *
 * @param g         (B, m) output
 * @param Lambda    (B, m) output
 * @param gh1       (B, m) output
 * @param H_nonneg  (B, n_nonneg) input cone scalings
 * @param eps       regularization (scalar, same for all batches in backward)
 */
void launch_diff_wb_s_elim_diagonals(
    double* g, double* Lambda, double* gh1,
    const double* H_nonneg, double eps,
    int64_t batch, int64_t m, int64_t k, int64_t n_nonneg,
    cudaStream_t stream = 0);

/**
 * Compute D_x diagonal for the reduced x-block after s-elimination.
 *   D_x[j] = P[j]^2 + eps + sum_{sparse rows touching col j} Lambda[k+nonneg_idx] * a_val^2
 *
 * Same CSC structure as forward d_tilde_inv but with Lambda weights and P^2.
 *
 * @param D_x       (B, n) output
 * @param P_diag    (B, n) P diagonal values
 * @param Lambda    (B, m) s-elimination weight
 * @param A_s_vals  (B, n_sparse) sparse nonneg A values
 * @param eps       regularization scalar
 */
void launch_diff_wb_compute_D_x(
    double* D_x,
    const double* P_diag, const double* Lambda,
    const double* A_s_vals, double eps,
    const int64_t* sparse_nonneg_idx,
    const int64_t* col_offsets, const int64_t* col_sparse_rows,
    int64_t batch, int64_t n, int64_t m, int64_t k,
    int64_t n_nonneg, int64_t n_sparse,
    cudaStream_t stream = 0);

/**
 * Compute D_z diagonal for nonneg z-block after s-elimination.
 *   D_z[i] = 2 + eps - (1+h[i])^2 / (1+h[i]^2+eps) + c2_nonneg[i]^2
 *
 * Also computes D_z_inv = 1/D_z for sparse/empty nonneg recovery.
 *
 * @param D_z       (B, n_nonneg) output
 * @param D_z_inv   (B, n_nonneg) output
 * @param H_nonneg  (B, n_nonneg) cone scalings
 * @param c2        (B, m) HSDE coefficient (read c2[k+i] for nonneg)
 * @param eps       regularization scalar
 */
void launch_diff_wb_compute_D_z(
    double* D_z, double* D_z_inv,
    const double* H_nonneg, const double* c2, double eps,
    int64_t batch, int64_t m, int64_t k, int64_t n_nonneg,
    cudaStream_t stream = 0);

/**
 * Build F_ext from forward F_all + c1 row.
 * F_ext (B, n, k_ext) row-major = [F_all; c1'] where k_ext = k_total + 1.
 * Copies F_all rows 0..k_total-1, then sets row k_total = c1.
 *
 * @param F_ext     (B_F, n, k_ext) output, row-major
 * @param F_all     (B_F, n, k_total) input, row-major
 * @param c1        (B, n) HSDE coefficient
 * @param B_F       1 if F_all shared, B if per-batch
 */
void launch_diff_wb_build_F_ext(
    double* F_ext,
    const double* F_all, const double* c1,
    int64_t B_F, int64_t n, int64_t k_total, int64_t k_ext,
    cudaStream_t stream = 0);

/**
 * Compute Lambda_F weights for F_ext rows.
 * For zero cone rows (0..k-1):   Lambda_F[i] = Lambda_zero = (1+eps)/(2+eps)
 * For dense nonneg rows (k..k_total-1): Lambda_F[k+j] = Lambda[k + dense_idx[j]]
 * For c1 row (k_total):          Lambda_F[k_total] = 1.0
 */
void launch_diff_wb_compute_Lambda_F(
    double* Lambda_F,
    const double* Lambda,
    const int64_t* dense_nonneg_idx,
    double eps,
    int64_t batch, int64_t m, int64_t k, int64_t k_d, int64_t k_total, int64_t k_ext,
    cudaStream_t stream = 0);

/**
 * Compute C_all_ext inverse diagonal for Schur complement.
 * For zero rows (0..k-1):        C_inv[i] = 1/Lambda_F[i]
 * For dense nonneg (k..k_total-1): C_inv[k+j] = 1/Lambda_F[k+j]
 * For c1 row (k_total):          C_inv[k_total] = 1.0 (since weight is 1)
 *
 * Also adds C_inv to Schur diagonal after GEMM: S[i,i] += C_inv[i]

void launch_diff_wb_set_schur_diag(

/**
 * Compute τ-elimination quantities.
 * v_x = P*q - A'*Lambda*b + c1*c3  (n-vector per batch)
 * v_z = A*q - (I - diag((1+h)*g))*b + c2*c3  (m-vector per batch)
 * sigma = q'q + b'*Lambda*b + c3^2 + eps  (scalar per batch)
 *
 * For v_x: the A'*Lambda*b term uses same sparse/F_all decomposition.
 * This kernel handles the diagonal parts only (P*q, sparse A terms, c1*c3).
 * The F_all GEMV part is done via cuBLAS.
 */

    double* v_x, double* v_z, double* sigma,

    const double* c1, const double* c2, const double* c3,

    const double* A_s_vals,
    const int64_t* sparse_nonneg_idx, const int64_t* sparse_col,
    const int64_t* col_offsets, const int64_t* col_sparse_rows,
    double eps,
    int64_t batch, int64_t n, int64_t m, int64_t k, int64_t n_nonneg, int64_t n_sparse,
    cudaStream_t stream = 0);

/**
 * RHS correction after s-elimination.
 * r_tilde_x = r_x + A'*(g*r_s)  (sparse part: CSC scatter)
 * r_tilde_z = r_z + diag(gh1)*r_s
 * r_tilde_tau = r_tau - b'*(g*r_s)
 *
 * This kernel handles the diagonal/sparse parts. F_all GEMV for dense A' done via cuBLAS.
 *
 * @param rhs_bar   (B, jdim) input: [r_x; r_z; r_s; r_tau]
 * @param rt_x      (B, n) output (sparse A' contribution only — add F_all GEMV after)
 * @param rt_z      (B, m) output

 * @param gh1       (B, m) = g*(1+h)
 * @param b         (B, m) constraint vector

void launch_diff_wb_s_elim_rhs(

// ============================================================
// Backward pass kernels

__global__ void diff_wb_s_elim_diagonals_kernel(
    double* g, double* Lambda, double* gh1,
    const double* H_nonneg, double eps,
    int64_t batch, int64_t m, int64_t k, int64_t n_nonneg)
{
    int64_t b = blockIdx.x;
    if (b >= batch) return;

    double* g_b = g + b * m;
    double* L_b = Lambda + b * m;
    double* gh_b = gh1 + b * m;
    const double* H_b = H_nonneg + b * n_nonneg;

    // Zero cones: h = 1
    for (int64_t i = threadIdx.x; i < k; i += blockDim.x) {
        double h = 1.0;
        double denom = 1.0 + h * h + eps;  // = 2 + eps
        g_b[i] = 1.0 / denom;
        L_b[i] = 1.0 - g_b[i];
        gh_b[i] = g_b[i] * (1.0 + h);  // = 2/(2+eps)
    }

    // Nonneg cones
    for (int64_t i = threadIdx.x; i < n_nonneg; i += blockDim.x) {
        double h = H_b[i];
        double denom = 1.0 + h * h + eps;
        double gi = 1.0 / denom;
        g_b[k + i] = gi;
        L_b[k + i] = 1.0 - gi;
        gh_b[k + i] = gi * (1.0 + h);
    }
}

void launch_diff_wb_s_elim_diagonals(
    double* g, double* Lambda, double* gh1,
    const double* H_nonneg, double eps,
    int64_t batch, int64_t m, int64_t k, int64_t n_nonneg,
    cudaStream_t stream)
{
    int threads = std::min((int)m, 256);
    diff_wb_s_elim_diagonals_kernel<<<(int)batch, threads, 0, stream>>>(
        g, Lambda, gh1, H_nonneg, eps, batch, m, k, n_nonneg);
}

__global__ void diff_wb_compute_D_x_kernel(
    double* D_x,
    const double* P_diag, const double* Lambda,
    const double* A_s_vals, double eps,
    const int64_t* sparse_nonneg_idx,
    const int64_t* col_offsets, const int64_t* col_sparse_rows,
    int64_t batch, int64_t n, int64_t m, int64_t k,
    int64_t n_nonneg, int64_t n_sparse)
{
    int64_t b = blockIdx.x;
    if (b >= batch) return;

    double* D_b = D_x + b * n;
    const double* P_b = P_diag + b * n;
    const double* L_b = Lambda + b * m;
    const double* As_b = A_s_vals + b * n_sparse;

    for (int64_t j = threadIdx.x; j < n; j += blockDim.x) {
        double pj = P_b[j];
        double val = pj * pj + eps;

        // Accumulate sparse nonneg contributions via CSC
        for (int64_t p = col_offsets[j]; p < col_offsets[j + 1]; ++p) {
            int64_t sr = col_sparse_rows[p];
            int64_t ni = sparse_nonneg_idx[sr];
            double a = As_b[sr];
            val += L_b[k + ni] * a * a;
        }

        D_b[j] = val;
    }
}

void launch_diff_wb_compute_D_x(
    double* D_x,
    const double* P_diag, const double* Lambda,
    const double* A_s_vals, double eps,
    const int64_t* sparse_nonneg_idx,
    const int64_t* col_offsets, const int64_t* col_sparse_rows,
    int64_t batch, int64_t n, int64_t m, int64_t k,
    int64_t n_nonneg, int64_t n_sparse,
    cudaStream_t stream)
{
    int threads = std::min((int)n, 256);
    diff_wb_compute_D_x_kernel<<<(int)batch, threads, 0, stream>>>(
        D_x, P_diag, Lambda, A_s_vals, eps,
        sparse_nonneg_idx, col_offsets, col_sparse_rows,
        batch, n, m, k, n_nonneg, n_sparse);
}

__global__ void diff_wb_compute_D_z_kernel(
    double* D_z, double* D_z_inv,
    const double* H_nonneg, const double* c2, double eps,
    int64_t batch, int64_t m, int64_t k, int64_t n_nonneg)
{
    int64_t b = blockIdx.x;
    if (b >= batch) return;

    double* Dz_b = D_z + b * n_nonneg;
    double* Dzi_b = D_z_inv + b * n_nonneg;
    const double* H_b = H_nonneg + b * n_nonneg;
    const double* c2_b = c2 + b * m;

    for (int64_t i = threadIdx.x; i < n_nonneg; i += blockDim.x) {
        double h = H_b[i];
        double c2i = c2_b[k + i];
        double val = 2.0 + eps - (1.0 + h) * (1.0 + h) / (1.0 + h * h + eps) + c2i * c2i;
        Dz_b[i] = val;
        Dzi_b[i] = 1.0 / val;
    }
}

void launch_diff_wb_compute_D_z(
    double* D_z, double* D_z_inv,
    const double* H_nonneg, const double* c2, double eps,
    int64_t batch, int64_t m, int64_t k, int64_t n_nonneg,
    cudaStream_t stream)
{
    int threads = std::min((int)n_nonneg, 256);
    if (threads == 0) return;
    diff_wb_compute_D_z_kernel<<<(int)batch, threads, 0, stream>>>(
        D_z, D_z_inv, H_nonneg, c2, eps, batch, m, k, n_nonneg);
}

__global__ void diff_wb_build_F_ext_kernel(
    double* F_ext, const double* F_all, const double* c1,
    int64_t B_F, int64_t n, int64_t k_total, int64_t k_ext)
{
    int64_t b = blockIdx.x;
    if (b >= B_F) return;

    const double* F_b = F_all + b * n * k_total;
    double* Fe_b = F_ext + b * n * k_ext;
    const double* c1_b = c1 + b * n;  // c1 always per-batch

    for (int64_t j = threadIdx.x; j < n; j += blockDim.x) {
        // Copy existing F_all rows
        for (int64_t i = 0; i < k_total; ++i) {
            Fe_b[j * k_ext + i] = F_b[j * k_total + i];
        }
        // Append c1 as last row
        Fe_b[j * k_ext + k_total] = c1_b[j];
    }
}

void launch_diff_wb_build_F_ext(
    double* F_ext, const double* F_all, const double* c1,
    int64_t B_F, int64_t n, int64_t k_total, int64_t k_ext,
    cudaStream_t stream)
{
    int threads = std::min((int)n, 256);
    diff_wb_build_F_ext_kernel<<<(int)B_F, threads, 0, stream>>>(
        F_ext, F_all, c1, B_F, n, k_total, k_ext);
}

__global__ void diff_wb_compute_Lambda_F_kernel(
    double* Lambda_F, const double* Lambda,
    const int64_t* dense_nonneg_idx, double eps,
    int64_t batch, int64_t m, int64_t k, int64_t k_d, int64_t k_total, int64_t k_ext)
{
    int64_t b = blockIdx.x;
    if (b >= batch) return;

    double* LF_b = Lambda_F + b * k_ext;
    const double* L_b = Lambda + b * m;

    for (int64_t i = threadIdx.x; i < k_ext; i += blockDim.x) {
        if (i < k) {
            // Zero cone: Lambda_zero = (1+eps)/(2+eps)
            LF_b[i] = (1.0 + eps) / (2.0 + eps);
        } else if (i < k_total) {
            // Dense nonneg
            int64_t d = i - k;
            int64_t ni = dense_nonneg_idx[d];
            LF_b[i] = L_b[k + ni];
        } else {
            // c1 row: weight = 1
            LF_b[i] = 1.0;
        }
    }
}

void launch_diff_wb_compute_Lambda_F(
    double* Lambda_F, const double* Lambda,
    const int64_t* dense_nonneg_idx, double eps,
    int64_t batch, int64_t m, int64_t k, int64_t k_d, int64_t k_total, int64_t k_ext,
    cudaStream_t stream)
{
    int threads = std::min((int)k_ext, 256);
    diff_wb_compute_Lambda_F_kernel<<<(int)batch, threads, 0, stream>>>(
        Lambda_F, Lambda, dense_nonneg_idx, eps, batch, m, k, k_d, k_total, k_ext);
}

__global__ void diff_wb_set_schur_diag_kernel(
    double* S, const double* Lambda_F,
    int64_t batch, int64_t k_ext)
{
    int64_t b = blockIdx.x;
    if (b >= batch) return;

    double* S_b = S + b * k_ext * k_ext;
    const double* LF_b = Lambda_F + b * k_ext;

    for (int64_t i = threadIdx.x; i < k_ext; i += blockDim.x) {
        S_b[i * k_ext + i] += 1.0 / LF_b[i];
    }
}

    const int64_t* col_offsets, const int64_t* col_sparse_rows,
    double eps,
    int64_t batch, int64_t n, int64_t m, int64_t k, int64_t n_nonneg, int64_t n_sparse)
{
    int64_t bi = blockIdx.x;
    if (bi >= batch) return;

    double* vx_b = v_x + bi * n;
    double* vz_b = v_z + bi * m;
    const double* P_b = P_diag + bi * n;
    const double* q_b = q + bi * n;
    const double* b_b = b + bi * m;
    const double* c1_b = c1 + bi * n;
    const double* c2_b = c2 + bi * m;
    double c3_b = c3[bi];
    const double* L_b = Lambda + bi * m;
    const double* g_b = g + bi * m;
    const double* gh1_b = gh1 + bi * m;
    const double* As_b = A_s_vals + bi * n_sparse;

    // v_x[j] = P[j]*q[j] + c1[j]*c3 - sum_sparse_rows Lambda[row] * a * b[row]
    // (The F_all GEMV for dense A' * Lambda * b is added externally)
    for (int64_t j = threadIdx.x; j < n; j += blockDim.x) {
        double val = P_b[j] * q_b[j] + c1_b[j] * c3_b;
        // Sparse A' * Lambda * b contribution
        for (int64_t p = col_offsets[j]; p < col_offsets[j + 1]; ++p) {
            int64_t sr = col_sparse_rows[p];
            int64_t ni = sparse_nonneg_idx[sr];
            double a = As_b[sr];
            val -= L_b[k + ni] * a * b_b[k + ni];
        }
        vx_b[j] = val;
    }

    // v_z[i] = c2[i]*c3 - (1 - gh1[i]) * b[i]
    // For zero cones (i < k): A_row*q is in F_all GEMV, handle externally
    // Here just compute the diagonal parts
    for (int64_t i = threadIdx.x; i < m; i += blockDim.x) {
        vz_b[i] = c2_b[i] * c3_b - (1.0 - gh1_b[i]) * b_b[i];
        // Note: A*q contribution for zero/dense rows added via F_all GEMV
    }

    // sigma = q'q + b'*Lambda*b + c3^2 + eps (reduction by thread 0)
    __syncthreads();
    if (threadIdx.x == 0) {
        double s = c3_b * c3_b + eps;
        for (int64_t j = 0; j < n; ++j) s += q_b[j] * q_b[j];
        for (int64_t i = 0; i < m; ++i) s += L_b[i] * b_b[i] * b_b[i];
        sigma[bi] = s;
    }
}

__global__ void diff_wb_s_elim_rhs_kernel(
    const double* rhs_bar, double* rt_x, double* rt_z, double* rt_tau,
    const double* g, const double* gh1, const double* b,
    const double* A_s_vals,
    const int64_t* sparse_nonneg_idx, const int64_t* sparse_col,
    const int64_t* col_offsets, const int64_t* col_sparse_rows,
    int64_t batch, int64_t n, int64_t m, int64_t k,
    int64_t n_nonneg, int64_t n_sparse)
{
    int64_t bi = blockIdx.x;
    if (bi >= batch) return;

    int64_t jdim = n + 2 * m + 1;
    const double* rhs_b = rhs_bar + bi * jdim;
    const double* r_x = rhs_b;
    const double* r_z = rhs_b + n;
    const double* r_s = rhs_b + n + m;
    double r_tau = rhs_b[jdim - 1];

    double* rtx_b = rt_x + bi * n;
    double* rtz_b = rt_z + bi * m;
    const double* g_b = g + bi * m;
    const double* gh1_b = gh1 + bi * m;
    const double* b_b = b + bi * m;
    const double* As_b = A_s_vals + bi * n_sparse;

    // rt_x = r_x + A_sparse' * (g * r_s)  [sparse part only]
    for (int64_t j = threadIdx.x; j < n; j += blockDim.x) {
        double val = r_x[j];
        for (int64_t p = col_offsets[j]; p < col_offsets[j + 1]; ++p) {
            int64_t sr = col_sparse_rows[p];
            int64_t ni = sparse_nonneg_idx[sr];
            double a = As_b[sr];
            val += a * g_b[k + ni] * r_s[k + ni];
        }
        rtx_b[j] = val;
    }

    // rt_z = r_z + diag(gh1) * r_s
    for (int64_t i = threadIdx.x; i < m; i += blockDim.x) {
        rtz_b[i] = r_z[i] + gh1_b[i] * r_s[i];
    }

    // rt_tau = r_tau - b' * (g * r_s)
    __syncthreads();
    if (threadIdx.x == 0) {
        double val = r_tau;
        for (int64_t i = 0; i < m; ++i) {
            val -= b_b[i] * g_b[i] * r_s[i];
        }
        rt_tau[bi] = val;
    }
}

__global__ void diff_wb_tau_elim_rhs_kernel(
    double* rhat_x, double* rhat_z,
    const double* rt_x, const double* rt_z,
    const double* rt_tau, const double* v_x, const double* v_z,
    const double* sigma,
    int64_t batch, int64_t n, int64_t m)
{
    int64_t bi = blockIdx.x;
    if (bi >= batch) return;

    double alpha = rt_tau[bi] / sigma[bi];

    double* rx_b = rhat_x + bi * n;
    double* rz_b = rhat_z + bi * m;
    const double* rtx_b = rt_x + bi * n;
    const double* rtz_b = rt_z + bi * m;
    const double* vx_b = v_x + bi * n;
    const double* vz_b = v_z + bi * m;

    for (int64_t j = threadIdx.x; j < n; j += blockDim.x) {
        rx_b[j] = rtx_b[j] - alpha * vx_b[j];
    }
    for (int64_t i = threadIdx.x; i < m; i += blockDim.x) {
        rz_b[i] = rtz_b[i] - alpha * vz_b[i];
    }
}

}

__global__ void diff_wb_recover_y_tau_kernel(
    double* y_tau,
    const double* rt_tau, const double* v_x, const double* v_z,
    const double* y_x, const double* y_z, const double* sigma,
    int64_t batch, int64_t n, int64_t m)
{
    int64_t bi = blockIdx.x;
    if (bi >= batch) return;

    if (threadIdx.x == 0) {
        const double* vx = v_x + bi * n;
        const double* vz = v_z + bi * m;
        const double* yx = y_x + bi * n;
        const double* yz = y_z + bi * m;

        double val = rt_tau[bi];
        for (int64_t j = 0; j < n; ++j) val -= vx[j] * yx[j];
        for (int64_t i = 0; i < m; ++i) val -= vz[i] * yz[i];
        y_tau[bi] = val / sigma[bi];
    }
}

__global__ void diff_wb_recover_y_s_kernel(
    double* y_s,
    const double* rhs_bar, const double* y_x,
    const double* y_z, const double* y_tau,
    const double* g, const double* gh1, const double* b,
    const double* A_s_vals,
    const int64_t* sparse_nonneg_idx, const int64_t* sparse_col,
    int64_t batch, int64_t n, int64_t m, int64_t k,
    int64_t n_nonneg, int64_t n_sparse)
{
    int64_t bi = blockIdx.x;
    if (bi >= batch) return;

    int64_t jdim = n + 2 * m + 1;
    const double* r_s = rhs_bar + bi * jdim + n + m;
    double* ys_b = y_s + bi * m;
    const double* yx_b = y_x + bi * n;
    const double* yz_b = y_z + bi * m;
    double ytau = y_tau[bi];
    const double* g_b = g + bi * m;
    const double* gh1_b = gh1 + bi * m;
    const double* b_b = b + bi * m;

    // y_s[i] = g[i] * (r_s[i] + A_row_i * y_x + (1+h)*y_z[i] - b[i]*y_tau)
    // For zero cones: A*y_x contribution is from F_all GEMV (added externally)
    // For sparse nonneg: A_row * y_x = a * y_x[col]
    // For empty: A_row * y_x = 0

    for (int64_t i = threadIdx.x; i < m; i += blockDim.x) {
        double val = r_s[i] + gh1_b[i] / g_b[i] * g_b[i] * yz_b[i] - b_b[i] * ytau;
        // Simplify: gh1/g * g = gh1 = (1+h)*g ... wait, gh1 = g*(1+h).
        // (1+h)*y_z = gh1/g * y_z? No. We need (1+h)*y_z[i].
        // Since gh1[i] = g[i]*(1+h_i), we have (1+h_i) = gh1[i]/g[i].
        // But we want g[i] * ((1+h_i)*y_z[i]) = gh1[i]*y_z[i].
        // So y_s[i] = g[i]*r_s[i] + gh1[i]*y_z[i] - g[i]*b[i]*y_tau + g[i]*A_row*y_x

        ys_b[i] = g_b[i] * r_s[i] + gh1_b[i] * yz_b[i] - g_b[i] * b_b[i] * ytau;
        // A*y_x contribution added below for sparse rows, or externally for zero/dense
    }

    __syncthreads();

    // Add sparse A*y_x: for sparse nonneg row sr, A_row * y_x = a * y_x[col]
    for (int64_t sr = threadIdx.x; sr < n_sparse; sr += blockDim.x) {
        int64_t ni = sparse_nonneg_idx[sr];
        int64_t col = sparse_col[sr];
        double a = A_s_vals[bi * n_sparse + sr];
        ys_b[k + ni] += g_b[k + ni] * a * yx_b[col];
    }
}

__global__ void diff_wb_J_matvec_diag_kernel(
    double* y_out,
    const double* w_x, const double* w_z, const double* w_s,
    const double* w_tau,
    const double* P_diag, const double* H_nonneg,
    const double* q, const double* b,
    const double* c1, const double* c2, const double* c3,
    const double* A_s_vals,
    const int64_t* sparse_nonneg_idx, const int64_t* sparse_col,
    const int64_t* col_offsets, const int64_t* col_sparse_rows,
    int64_t batch, int64_t n, int64_t m, int64_t k,
    int64_t n_nonneg, int64_t n_sparse)
{
    int64_t bi = blockIdx.x;
    if (bi >= batch) return;

    int64_t jdim = n + 2 * m + 1;
    double* out = y_out + bi * jdim;
    const double* wx = w_x + bi * n;
    const double* wz = w_z + bi * m;
    const double* ws = w_s + bi * m;
    double wtau = w_tau[bi];
    const double* P_b = P_diag + bi * n;
    const double* H_b = H_nonneg + bi * n_nonneg;
    const double* q_b = q + bi * n;
    const double* b_b = b + bi * m;
    const double* c1_b = c1 + bi * n;
    const double* c2_b = c2 + bi * m;
    double c3_b = c3[bi];
    const double* As_b = A_s_vals + bi * n_sparse;

    // Row 0: y_out[0:n] = P*w_x + A'*w_z + q*w_tau
    // Diagonal P + q*tau. A' sparse contribution via CSC. Dense A' via cuBLAS.
    for (int64_t j = threadIdx.x; j < n; j += blockDim.x) {
        double val = P_b[j] * wx[j] + q_b[j] * wtau;
        // Sparse A' * w_z: for each sparse nonneg row touching col j
        for (int64_t p = col_offsets[j]; p < col_offsets[j + 1]; ++p) {
            int64_t sr = col_sparse_rows[p];
            int64_t ni = sparse_nonneg_idx[sr];
            double a = As_b[sr];
            val += a * wz[k + ni];
        }
        out[j] = val;
        // Note: A_zero' * w_z_zero and A_dense' * w_z_dense added via cuBLAS GEMV
    }

    // Row 1: y_out[n:n+m] = A*w_x + w_z - w_s - b*w_tau
    // Sparse A*w_x. Element-wise w_z - w_s - b*tau.
    for (int64_t i = threadIdx.x; i < m; i += blockDim.x) {
        out[n + i] = wz[i] - ws[i] - b_b[i] * wtau;
        // Sparse A*w_x for nonneg rows
        // Zero/dense A*w_x via cuBLAS
    }
    // Add sparse A*w_x contributions
    for (int64_t sr = threadIdx.x; sr < n_sparse; sr += blockDim.x) {
        int64_t ni = sparse_nonneg_idx[sr];
        int64_t col = sparse_col[sr];
        double a = As_b[sr];
        atomicAdd(&out[n + k + ni], a * wx[col]);
    }

    // Row 2: y_out[n+m:n+2m] = w_z - H*w_s
    for (int64_t i = threadIdx.x; i < m; i += blockDim.x) {
        double h;
        if (i < k) {
            h = 1.0;  // zero cone H = I
        } else {
            h = H_b[i - k];
        }
        out[n + m + i] = wz[i] - h * ws[i];
    }

    // Row 3: y_out[n+2m] = c1'*w_x + c2'*w_z + c3*w_tau
    __syncthreads();
    if (threadIdx.x == 0) {
        double val = c3_b * wtau;
        for (int64_t j = 0; j < n; ++j) val += c1_b[j] * wx[j];
        for (int64_t i = 0; i < m; ++i) val += c2_b[i] * wz[i];
        out[jdim - 1] = val;
    }
}

/**
 * @file diff_woodbury.hpp
 * @brief Woodbury-specialized backward pass via direct Schur complement solve
 *
 * Solves (J'J + εI)w = rhs_bar, then y_out = J*w.
 * Exploits diagonal P + low-rank A structure via block elimination:
 *   1. Eliminate y_s (diagonal D_s = I + H² + εI)
 *   2. Eliminate y_τ (scalar Sherman-Morrison)
 *   3. Solve reduced (n+m) via Woodbury: diagonal D_x + rank-k_ext F_ext
 *   4. Back-substitute for y_s, y_τ
 *   5. J-matvec: y_out = J * w
 */

#pragma once

#include <cuda_runtime.h>
#include <cublas_v2.h>
#include <cusolverDn.h>
#include <cstdint>
#include <memory>

#include "moreau/cuda/utils.hpp"
#include "moreau/cones/cones.hpp"

namespace moreau {

struct WoodburyKKTData;

struct DiffWoodbury {
    int64_t n_ = 0, m_ = 0, k_ = 0, k_total_ = 0;
    int64_t k_ext_ = 0;   // k_total + 1 (extra row for c1)
    int64_t n_nonneg_ = 0, n_sparse_ = 0, n_empty_ = 0, k_d_ = 0;
    int64_t jdim_ = 0;    // n + 2m + 1
    int64_t batchSize_ = 0;

    static constexpr double eps_ = 1e-8;

    // ---- Borrowed from forward WoodburyKKTData (set by setup()) ----
    const double* F_all_ = nullptr;
    long long f_all_stride_ = 0;
    bool f_all_shared_ = false;
    const double* P_diag_ = nullptr;
    const double* A_s_vals_ = nullptr;
    const int64_t* sparse_nonneg_idx_ = nullptr;
    const int64_t* sparse_col_ = nullptr;
    const int64_t* col_offsets_ = nullptr;
    const int64_t* col_sparse_rows_ = nullptr;
    const int64_t* dense_nonneg_idx_ = nullptr;
    const int64_t* empty_nonneg_idx_ = nullptr;

    // ---- Per-backward-call data (set by setup()) ----
    const double* H_nonneg_ = nullptr;  // (B, n_nonneg)
    const double* q_ = nullptr;         // (B, n)
    const double* b_ = nullptr;         // (B, m)
    const double* c1_ = nullptr;        // (B, n)
    const double* c2_ = nullptr;        // (B, m)
    const double* c3_ = nullptr;        // (B, 1)

    // ---- s-elimination diagonals (B, m) ----
    device_unique_ptr<double> g_;       // 1/(1+h²+ε)
    device_unique_ptr<double> Lambda_;  // (h²+ε)/(1+h²+ε)
    device_unique_ptr<double> gh1_;     // g*(1+h)

    // ---- Reduced system diagonals ----
    device_unique_ptr<double> D_x_;        // (B, n) x-block diagonal
    device_unique_ptr<double> D_x_inv_;    // (B, n) 1/D_x
    device_unique_ptr<double> D_z_;        // (B, n_nonneg) nonneg z diagonal
    device_unique_ptr<double> D_z_inv_;    // (B, n_nonneg) 1/D_z
    device_unique_ptr<double> Lambda_F_;   // (B, k_ext) F_ext row weights
    device_unique_ptr<double> C_all_ext_;  // (B, k_ext) = 1/Lambda_F (Schur diag add)

    // ---- τ-elimination vectors ----
    device_unique_ptr<double> v_x_;     // (B, n)
    device_unique_ptr<double> v_z_;     // (B, m)
    device_unique_ptr<double> sigma_;   // (B)

    // ---- Extended F_all (B_F, n, k_ext) ----
    device_unique_ptr<double> F_ext_;   // F_all + c1 row
    long long f_ext_stride_ = 0;       // 0 if shared, n*k_ext if per-batch

    // ---- Schur complement ----
    device_unique_ptr<double> S_schur_;      // (B, k_ext, k_ext)

    s += 2 * batchSize_ * n_ * sizeof(double);
    s += 2 * batchSize_ * n_nonneg_ * sizeof(double);

    s += B_F * n_ * k_ext_ * sizeof(double);

    s += batchSize_ * n_nonneg_ * sizeof(double);

        double alpha = 1.0, beta = 1.0;
        cublasDgemmStridedBatched(cublas_, CUBLAS_OP_T, CUBLAS_OP_N,
            (int)n_, 1, (int)k_ext_,
            &alpha,
            F_ext_.get(), (int)k_ext_, f_ext_stride_,
            schur_rhs_.get(), (int)k_ext_, (long long)k_ext_,
            &beta,
            rhs_x_adj_.get(), (int)n_, (long long)n_,
            (int)batchSize_);
    }

    // 4. u = D_x_inv * rhs_x_adj
    launch_woodbury_elementwise_mul(
        Dinv_rhs_.get(), D_x_inv_.get(), rhs_x_adj_.get(),
        batchSize_ * n_, stream);

    // 5. v = F_ext @ u
    {
        double alpha = 1.0, beta = 0.0;
        cublasDgemmStridedBatched(cublas_, CUBLAS_OP_N, CUBLAS_OP_N,
            (int)k_ext_, 1, (int)n_,
            &alpha,
            F_ext_.get(), (int)k_ext_, f_ext_stride_,
            Dinv_rhs_.get(), (int)n_, (long long)n_,
            &beta,
            schur_rhs_.get(), (int)k_ext_, (long long)k_ext_,
            (int)batchSize_);
    }

    // 6. w = S^{-1} v (Cholesky solve)
    cudaMemcpyAsync(d_nu_.get(), schur_rhs_.get(),
                    sizeof(double) * batchSize_ * k_ext_,
                    cudaMemcpyDeviceToDevice, stream);
    if (batchSize_ == 1) {
        cusolverDnDpotrs(cusolver_, CUBLAS_FILL_MODE_LOWER,
            (int)k_ext_, 1, S_schur_.get(), (int)k_ext_,
            d_nu_.get(), (int)k_ext_, cusolver_info_.get());
    } else {
        cusolverDnDpotrsBatched(cusolver_, CUBLAS_FILL_MODE_LOWER,
            (int)k_ext_, 1, S_ptrs_.get(), (int)k_ext_,
            dnu_ptrs_.get(), (int)k_ext_,
            cusolver_info_.get(), (int)batchSize_);
    }

    // 7. Fdnu = F_ext' @ w
    {
        double alpha = 1.0, beta = 0.0;
        cublasDgemmStridedBatched(cublas_, CUBLAS_OP_T, CUBLAS_OP_N,
            (int)n_, 1, (int)k_ext_,
            &alpha,
            F_ext_.get(), (int)k_ext_, f_ext_stride_,
            d_nu_.get(), (int)k_ext_, (long long)k_ext_,
            &beta,
            Fdnu_.get(), (int)n_, (long long)n_,
            (int)batchSize_);
    }

    // 8. y_x = D_x_inv * (rhs_x_adj - Fdnu)
    launch_woodbury_dx_recovery(
        y_x_.get(), D_x_inv_.get(), rhs_x_adj_.get(), Fdnu_.get(),
        batchSize_ * n_, stream);

    // 9. y_z recovery: zero/dense from d_nu, sparse/empty from diagonal
    // dy_nu = d_nu - C_all_ext * rhs_nu
    launch_woodbury_dy_recovery(
        gemv_k_.get(), d_nu_.get(), C_all_ext_.get(), rhs_nu_.get(),
        batchSize_, k_ext_, stream);

    // y_z[0:k] = gemv_k[0:k] (zero cone)
    // y_z[k + dense_idx[j]] = gemv_k[k + j] (dense nonneg)
    // y_z[k + sparse_idx[j]] = D_z_inv[j] * (A_s*y_x[col] - rhs_lam[j])
    // y_z[k + empty_idx[j]] = -D_z_inv[j] * rhs_lam[j]

    // Scatter zero/dense dy into y_z
    // Sparse/empty recovery using D_z_inv
    if (n_nonneg_ > 0) {
        if (n_sparse_ > 0) {
            launch_woodbury_dlam_sparse(
                y_z_.get() + k_ * 0,  // offset handled inside kernel by nonneg_idx
                D_z_inv_.get(), y_x_.get(), rhs_lam_.get(),
                A_s_vals_, sparse_col_, sparse_nonneg_idx_,
                batchSize_, n_, n_nonneg_, n_sparse_, stream);
        }
        if (n_empty_ > 0) {
            launch_woodbury_dlam_empty(
                y_z_.get() + k_ * 0,
                D_z_inv_.get(), rhs_lam_.get(),
                empty_nonneg_idx_,
                batchSize_, n_nonneg_, n_empty_, stream);
        }
        if (k_d_ > 0) {
            launch_woodbury_scatter_dlam_dense(
                y_z_.get() + k_ * 0,
                gemv_k_.get(), batchSize_, k_, k_ext_, n_nonneg_,
                dense_nonneg_idx_, k_d_, stream);
        }
    }
    // y_z[0:k] from gemv_k[0:k]
    // (scatter zero-cone dy into y_z)
    // TODO: scatter kernel for zero-cone entries
}

void DiffWoodbury::solveAdjoint(const double* rhs_bar, double* y_out, cudaStream_t stream) {
    // Phase 0: Precompute diagonals + Schur factorization
    precompute(stream);

    // Phase 1-2: s and τ elimination on RHS
    eliminate_s_tau_rhs(rhs_bar, stream);

    // Phase 3: Woodbury solve on reduced (n+m) system
    solve_reduced(stream);

    // Phase 4-5: Back-substitute y_tau, y_s
    back_substitute(rhs_bar, stream);

    // Phase 6: J-matvec y_out = J * w
    J_matvec(y_out, stream);
}

Implementation Notes for the Engineer
Key patterns to follow
cuBLAS GEMV pattern: The forward solver uses cublasDgemmStridedBatched with M=k, N=1 (or 2 for solve2), K=n. For backward, same but with k_ext instead of k_total. The F_ext stride is n * k_ext per batch (always per-batch since c1 varies).

Sparse CSC pattern: Identical to forward solver. col_offsets[j]..col_offsets[j+1] gives the sparse rows touching column j. Each sparse row has exactly 1 nonzero with value A_s_vals[sr] at column sparse_col[sr].

No hot-path mallocs: All workspace allocated in constructor/setup. The lazy allocation in setup() uses a null-check pattern — allocate once on first call, reuse thereafter.

Zero cone H = I: In the HSDE Jacobian, zero cones have H = identity. So h=1 for zero cone dual variables. This is critical for the s-elimination diagonals.

F_all layout: Row-major (n, k_total) per batch, stored so cuBLAS sees (k_total, n) column-major. Same layout for F_ext (n, k_ext).

The c2 correction: The spec mentions c2c2’ rank-1 corrections to S_zz. For sparse/empty nonneg, c2[i]^2 is folded into D_z (done in launch_diff_wb_compute_D_z). For zero/dense rows, c2_zero creates a dense k×k correction. This is handled by the c1 row in F_ext — wait, actually c2 affects the z-block, not x-block. The c2_zero × c2_zero’ correction to the Schur complement needs a separate Sherman-Morrison step or to be folded in. If initial tests fail on precision, this is the most likely cause. The fix: add c2_zero as another row in F_ext (k_ext = k_total + 2), or apply one SM correction to the k_ext×k_ext Schur complement after factorization.

Debugging tips
Set MOREAU_DEBUG=1 to enable debug prints in backward()

Compare intermediate values (D_x, Lambda, S_schur diagonal) between Woodbury and cuDSS paths

The BackwardMatchesCuDSS test compares gradients between Woodbury and cuDSS — any mismatch points to a bug in the block elimination

Use nsys profile to verify no host-device syncs in the hot path
